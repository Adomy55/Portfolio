Drop any of these into this folder and the site will pick them up automatically —
no code changes needed. If a file is missing, the current placeholder art is used
instead, so you can replace them one at a time.

wallpaper.png   — background of the whole office stage. Any size; it's stretched
                  to cover an 880 x 460 box, so something close to that ratio
                  (roughly 2:1) will look least stretched.

floor.png       — a short, tileable strip for the platform surfaces. It repeats
                  sideways (repeat-x) at 28px tall, so a wide, short tile
                  (e.g. 64 x 28) works best.

door.png        — used for every door on every page (landing, hallway, project).
                  Drawn at 70 x 110 on the landing page and a bit smaller in the
                  hallway — a portrait image works best, roughly 70 x 110.

stairs.png      — the staircase connecting the two floors. It's stretched to
                  fill a 120 x 260 box.

desk.png        — sits in front of the CV door on the reception floor, purely
                  decorative. Drawn at roughly 110 x 64.

All are optional and independent — add one, all, or none.
